# TractFigure Studio

Figure-oriented tractography visualization suite.

## Current starter functionality

- DIPY-backed tractogram loading
- RAS+ world-millimeter normalization
- TRK, TCK, TRX, VTK, VTP, FIB, and DPY support
- NIfTI anatomical backgrounds
- PyVista streamline rendering
- Multiple tract layers
- Openly licensed demonstration data

## Installation

```bash
uv sync --all-extras
source .venv/bin/activate
